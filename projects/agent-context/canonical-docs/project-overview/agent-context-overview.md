# Canonical Doc

## Summary

Agent-context is an authoring repository for bounded-agent workflow design and Markdown source materials that can later be extracted into ai-inst modules and skills.

## Guidance

- The project exists to design and refine low-cost agent bootstrap and routing behavior rather than to store project-specific truth for arbitrary target repositories.
- Markdown in this repository should be treated as authoring material for behavior patterns, module content, skill content, and harness design notes.
- Runtime work on a target repository should rely on project-memory for project-specific overview, routing, rationale, planning, and evidence.
- The preferred long-term flow is: author patterns in agent-context, deliver behavior through opencode and ai-inst, and consume project context through project-memory.
- The repository should optimize for clear behavior design and extraction readiness rather than for exhaustive sidecar coverage of an external codebase.
