# Decision

## Context

Выбор схемы авторизации для арт-платформы. ЦА — русские художники, у большинства есть VK и Telegram.

## Decision

Основные методы: Telegram Login + VK OAuth. Fallback: email + пароль. Токены: JWT access (15 мин, в памяти клиента) + refresh token (UUID, 7 дней, httpOnly cookie, хранится в БД). Пароли: bcrypt или argon2. Rate limiting на login/register. Роли: user, moderator, admin (enum в БД + guards в NestJS). При бане — удаление всех refresh-токенов пользователя.

## Consequences

- Telegram Login даёт username для кнопки «написать в Telegram» бесплатно
- Email+пароль требует верификацию email и сброс пароля
- Refresh в БД позволяет мгновенно инвалидировать сессии при бане
