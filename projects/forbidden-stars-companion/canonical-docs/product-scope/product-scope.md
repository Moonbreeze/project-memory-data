# Canonical Doc

## Summary

Проект осознанно ограничен ролью companion-приложения и не должен превращаться в полный трекер всех систем и фаз Forbidden Stars.

## Guidance

- В текущий product scope входят только те механики, которые дают быструю практическую пользу во время живой партии: бой, боевые колоды, таймеры и планирование ресурсов на ход.
- К проекту не относится полный трекинг карты, систем, adjacency, размещения приказов, полного хода игры, перемещения по полю и других board-state аспектов.
- Проект не должен стремиться к полной цифровой адаптации всей партии и не должен подменять физическое состояние поля собственным полным state model.
- Сохранение партий, экспорт и импорт не являются обязательной частью текущего scope.
- Синхронизация устройств допустима как отложенное направление развития, если она поддерживает live-play сценарий и не требует расширения проекта до полного трекера всей игры.
- Приватная информация отдельных игроков не является обязательной частью продуктовой модели; предпочтителен общий открытый companion-экран для стола.
