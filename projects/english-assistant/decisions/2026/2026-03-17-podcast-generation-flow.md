# Decision

## Context

Основная фича MVP — генерация подкастов для изучения английского. Преподаватель задаёт параметры, агент генерирует сценарий диалога, после подтверждения TTS озвучивает его.

## Decision

Базовый флоу: пользователь задаёт параметры (тема, ключевые слова, уровень CEFR, темп) → агент генерирует сценарий диалога двух голосов (~2 мин) → пользователь подтверждает/редактирует → TTS генерирует MP3. Дополнительно: опциональный быстрый режим без подтверждения и возможность настройки системного промпта агента.

## Consequences

- Нужен UI для ввода параметров и редактирования сценария
- Сценарий хранится как структурированный текст (реплики с указанием голоса)
- TTS вызывается для каждого голоса отдельно, результаты склеиваются
- Быстрый режим — тот же пайплайн, но без шага подтверждения
- Ключевые слова должны буквально присутствовать в сгенерированном тексте — нужна валидация или явная инструкция в промпте
