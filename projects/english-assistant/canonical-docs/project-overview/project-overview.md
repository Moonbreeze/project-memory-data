# Canonical Doc

## Summary

AI-powered ассистент для преподавателя английского языка. Первая фича — генерация двухминутных подкастов-диалогов на заданную тему с контролем уровня, лексики и темпа.

## Guidance

- Целевая аудитория — преподаватель английского без IT-бэкграунда, UI должен быть интуитивным
- Монорепо: фронтенд (React + Redux Toolkit) и бэкенд (Node.js, TypeScript нативно через experimental-strip-types)
- Пакетный менеджер — pnpm
- Деплой на VPS
- Транспортный слой абстрагирован от бизнес-логики — первая реализация веб-сервис, но архитектура позволяет подключить Telegram и др.
- OpenAI — провайдер для LLM-агента (генерация сценария) и TTS (озвучка)
- На этапе разработки OpenAI заменяется моками
- Однопользовательский сценарий
- Подкаст: диалог двух голосов, ~2 минуты, MP3
- Параметры подкаста: тема, ключевые слова (изучаемая лексика, должна буквально прозвучать), уровень CEFR (A1–C2), темп (скорость TTS)
- Базовый флоу: ввод параметров → генерация сценария → подтверждение/редактирование пользователем → TTS → MP3
- Опционально: быстрый режим без подтверждения, настройка системного промпта агента
