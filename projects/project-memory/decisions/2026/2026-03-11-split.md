# Decision

## Context

The MVP safety boundaries, tests, typecheck, archive flow, and commit-scope enforcement are in place, but the current repository still colocates implementation code and private memory data.

## Decision

Treat repository separation as the next primary iteration: keep the tool repository publishable and move private memory into a separate repository with an explicit external memory root.

## Consequences

- tool and data lifecycles are decoupled
- tool repo can become public
- bootstrap and repository context must support separate toolRoot and memoryRoot
- do not add new user-facing features before the split is complete
